# Мир иначе / Свет інакш

Интерактивный сайт об альтернативной истории Беларуси для конкурса **ПАТРИОТ.by**.

Беларусь — главный герой. Точка перелома — **июнь 1941 года**. Вопрос проекта: какой могла бы стать страна, если бы катастрофу Великой Отечественной войны удалось предотвратить.

Две ветки:

- **Наша история** — то, что произошло, по проверяемым источникам.
- **Альтернатива** — художественная гипотеза о непрерывной мирной линии. Это не факт и не прогноз.

Каждое утверждение помечено как **факт**, **анализ** или **гипотеза**.

Языки: **русский** и **белорусский** (переключатель РУС / БЕЛ в шапке). По умолчанию — русский.

## Страницы

| Файл | Содержание |
|------|------------|
| `index.html` | Главная: ввод в проект |
| `history.html` | Цепочка исторических событий |
| `turning-point.html` | Точка перелома, 1941 |
| `timeline.html` | Шкала 1930–2026: реальность и альтернатива |
| `people.html` | Реальные биографии: факт слева, гипотеза справа |
| `future.html` | Альтернативное 2026: города и статистика |
| `simulation.html` | Пошаговая симуляция с выбором и итогом |
| `sources.html` | Источники, методология, «О проекте» |

На странице «Люди» — реальные исторические личности:

- **Василий Корж** (Пинск) — один из первых партизанских отрядов, 1941
- **Вера Хоружая** (Витебск) — подполье, 1942

Источники: pinsklib.by, warmuseum.by, sb.by, Archives of Belarus, belarus.by, Britannica и др. Список — на `sources.html`.


В HTML два варианта:

```html
<span data-lang="be">Па-беларуску</span>
<span data-lang="ru">По-русски</span>
```

Или на одном элементе:

```html
<a data-i18n-be="Пачаць" data-i18n-ru="Начать">Пачаць</a>
```

Выбор языка хранится в `localStorage` (`patriotLang`). Динамический контент: `data/be/` и `data/ru/`. Строки интерфейса: `js/i18n.js`.

## Данные

JSON в `data/be/` и `data/ru/` (по одному набору на язык):

`history.json` · `timeline.json` · `people.json` · `cities.json` · `statistics.json` · `scenarios.json` · `sources.json`

Страницы читают JSON через `fetch` и собирают DOM в соответствующих скриптах (`js/history.js`, `timeline.js`, `people.js`, `future.js`, `simulation.js`, `sources.js`, `turning-point.js`). Общая логика — `js/app.js`.

## Как открыть

Нужен локальный HTTP-сервер: `fetch` JSON не работает через `file://`.

```bash
cd /Users/<ваше_имя_пользователя>/Desktop/patriot.by
python3 -m http.server 8080
```

Подставь своё имя пользователя и путь к папке проекта, затем открой [http://localhost:8080](http://localhost:8080). Если страница не обновилась — **Ctrl+Shift+R**.

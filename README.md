# Мир иначе / Свет інакш

Интерактивный двуязычный сайт об альтернативной истории Беларуси для конкурса **ПАТРИОТ.by**.

Беларусь — главный герой. Точка перелома — **июнь 1941 года**. Проект спрашивает, какой могла бы стать страна, если бы катастрофу Великой Отечественной войны удалось предотвратить.

## Две ветки

- **Наша история** — то, что произошло, по проверяемым источникам.
- **Альтернатива** — художественная гипотеза о непрерывной мирной линии. Это не факт и не прогноз.

Каждое утверждение помечено как **факт**, **анализ** или **гипотеза** (сплошная или пунктирная рамка — без цветовых акцентов).

Языки: **русский** и **белорусский** (переключатель РУС / БЕЛ в шапке). По умолчанию — русский; выбор хранится в `localStorage` (`patriotLang`).

## Внешний вид

Интерфейс — ранний монохромный десктоп (чёрное на белом): окна с жёсткими тенями, пиксельный UI-шрифт (Pixelify Sans) и читаемый текст (Source Sans 3).

Фон сайта — текстура архивной папки (`media/bg/archive-folder.jpg`): картон, штампы «ДЕЛО №» / «АРХИВ», шнурок. Контент лежит на белых «листах» и окнах, чтобы текст оставался читаемым.

Главный экран — документное окно с разворотом **Наша история | Альтернатива** и кнопкой «Начать».

## Страницы

| Файл | Содержание |
|------|------------|
| `index.html` | Главная: окно-разворот, линия времени, точка 1941 |
| `history.html` | Цепочка исторических событий |
| `turning-point.html` | Точка перелома, 1941: выбор ветки |
| `timeline.html` | Шкала 1930–2026: реальность и альтернатива |
| `people.html` | Реальные биографии: факт слева, гипотеза справа |
| `future.html` | Альтернативное 2026: города и статистика |
| `simulation.html` | Пошаговая симуляция с выбором и итогом |
| `sources.html` | Источники, методология, «О проекте» |

На странице «Люди» — реальные исторические личности:

- **Василий Корж** (Пинск) — один из первых партизанских отрядов, 1941
- **Вера Хоружая** (Витебск) — подполье, 1942

Портреты: `media/korzh.jpg`, `media/khoruzhaya.jpg`. Источники: pinsklib.by, warmuseum.by, sb.by, Archives of Belarus, belarus.by, Britannica и др. Полный список — на `sources.html`.

## Структура

```
css/          стили (variables, onebit, hero, pages, …)
js/           app, i18n, страничные скрипты
data/be/      JSON на белорусском
data/ru/      JSON на русском
fonts/        Pixelify Sans, Source Sans 3
media/        favicon, портреты, фон архивной папки
*.html        страницы
```

Данные: `history.json` · `timeline.json` · `people.json` · `cities.json` · `statistics.json` · `scenarios.json` · `sources.json`.

Страницы читают JSON через `fetch` и собирают DOM в `js/history.js`, `timeline.js`, `people.js`, `future.js`, `simulation.js`, `sources.js`, `turning-point.js`. Общая логика — `js/app.js`, строки интерфейса — `js/i18n.js`.

## Языки в разметке

```html
<span data-lang="be">Па-беларуску</span>
<span data-lang="ru">По-русски</span>
```

или:

```html
<a data-i18n-be="Пачаць" data-i18n-ru="Начать">Пачаць</a>
```

## Как открыть

Нужен локальный HTTP-сервер: `fetch` JSON не работает через `file://`.

```bash
cd /path/to/patriot.by
python3 -m http.server 8080
```

Открой [http://localhost:8080](http://localhost:8080). Если страница не обновилась — **Ctrl+Shift+R** (на Mac — **Cmd+Shift+R**).
